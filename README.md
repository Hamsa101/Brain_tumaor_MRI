# Brain Tumor MRI Dataset Analysis

## Project Overview
This project analyzes Brain Tumor MRI images using Python and data visualization techniques.

## Dataset
- **Source:** [Kaggle Brain Tumor MRI Dataset](https://www.kaggle.com/datasets/masoudnickparvar/brain-tumor-mri-dataset)
- **Total images analyzed:** 7,200
- **Categories:** Glioma, Meningioma, No Tumor, Pituitary
- **Training images:** 5,600
- **Testing images:** 1,600

## Technologies
- Python
- Google Colab
- Pandas
- Matplotlib
- Pillow
- GitHub

## Analysis
The dataset contains four equally represented categories, with 1,800 images in each. The analysis includes image counts, class distribution visualization and sample MRI images.

## Project Files
- `brain_tumor_analysis.ipynb` - Analysis notebook
- `class_distribution.png` - Class distribution chart
- `sample_mri_images.png` - Sample MRI images

## Conclusion
The dataset has a balanced class distribution and can be used for further machine learning experiments in brain MRI image classification.
